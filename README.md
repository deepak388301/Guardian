# 🛡️ Guardian — Women's Safety & Emergency Support Platform

A React-based web application designed to provide women with fast access to emergency resources, safety tools, and support information — built with a clean, accessible UI.

---

## What It Does

Guardian is a safety-focused web platform that gives users quick access to emergency contacts, location-based resources, and safety features — all in one place. Built with a modern React + Vite stack and styled with Tailwind CSS.

---

## Tech Stack

| Layer | Technology |
|---|---|
| Frontend Framework | React |
| Build Tool | Vite |
| Styling | Tailwind CSS |
| Animation | Motion (Framer Motion) |
| Language | JavaScript |

---

## Features

- Emergency resource access with a minimal, fast-loading interface
- Clean, mobile-responsive design using Tailwind CSS
- Smooth UI transitions powered by Motion
- Structured for easy extension with new safety features

## Getting Started

### Prerequisites

- Node.js 18+
- npm

### Installation

```bash
git clone https://github.com/deepak388301/Guardian.git
cd Guardian
npm install
```

### Development Server

```bash
npm run dev
```

Open `http://localhost:5173` in your browser.

### Production Build

```bash
npm run build
```

## Motivation

Personal safety tools are often buried inside complex apps or require sign-up flows. Guardian aims to be instant — no barrier between a user and the information they need in an emergency.
